# E-Surat BPRS Sragen

Aplikasi manajemen **surat masuk & surat keluar** dengan disposisi, persetujuan berjenjang, tanda tangan + QR verifikasi, dan notifikasi. Dijalankan on-premise.

- Stack: Laravel + Filament + MySQL
- Mulai dari: **`AGENTS.md`** → `docs/01-PRD.md` → `docs/05-PROMPT-CODEX.md`

## Cara memulai (untuk manusia)
1. Buat repo kosong, salin seluruh isi folder ini (AGENTS.md, README.md, docs/).
2. Jalankan Prompt **M0** dari `docs/05-PROMPT-CODEX.md` di Codex.
3. Review hasil, merge ke `develop`, lanjut milestone berikutnya.
4. Setelah tiap milestone, jalankan Prompt QA untuk Antigravity (di dokumen yang sama).
