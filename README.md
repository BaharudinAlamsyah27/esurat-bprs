# E-Surat BPRS Sragen

Aplikasi **surat masuk & surat keluar** yang sederhana: data klasifikasi, data instansi, data pengguna, surat masuk (dengan Lembar Disposisi cetak), surat keluar, laporan, dan dashboard. Dijalankan on-premise.

- Stack: Laravel 12 + Filament + MySQL
- Mulai dari: **`AGENTS.md`** → `docs/01-PRD.md` → `docs/05-PROMPT-CODEX.md`
- Setup di Windows: `docs/08-PANDUAN-SETUP-LARAGON.md`
