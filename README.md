# E-Surat BPRS Sragen

Aplikasi **surat masuk, surat keluar, dan perjanjian kerjasama (PKS)** internal BPRS Sragen: data klasifikasi, data instansi, data pengguna (`Superadmin`, `Admin Persuratan`, `Pegawai`), surat masuk (dengan Lembar Disposisi cetak & disposisi digital), surat keluar, perjanjian kerjasama, laporan (PDF & Excel), dashboard, serta aplikasi mobile Android Flutter (`mobile_flutter/`). Dijalankan on-premise.

- **Stack Web:** Laravel 12 + Filament 3 + MySQL 8
- **Stack Mobile (`mobile_flutter/`):** Flutter 3 + Sanctum Bearer API + Firebase Cloud Messaging (FCM)
