# Panduan Pengguna E-Surat BPRS Sragen

## Untuk Admin

**Masuk:** buka alamat aplikasi kantor, masukkan nama pengguna dan kata sandi, lalu pilih **Masuk**.

**Mencatat surat masuk:** buka **Surat Masuk** → **Catat Surat Masuk**. Isi nomor surat, pengirim, perihal, klasifikasi, tanggal surat, dan tanggal diterima. Pilih **Simpan**. Jika perlu, buka surat lalu pilih **Disposisi**, isi satu lembar disposisi, kemudian **Simpan & Cetak**.

**Mencatat surat keluar:** buka **Surat Keluar** → **Catat Surat Keluar**. Isi tujuan, perihal, klasifikasi, dan tanggal. Nomor surat dibuat otomatis; Admin dapat mengisi nomor manual yang belum dipakai. Pilih **Simpan**.

**Laporan:** buka menu **Laporan**, pilih tanggal awal dan akhir, lalu **Tampilkan laporan**. Gunakan **Cetak**, **Unduh PDF**, atau **Unduh Excel**.

**Data dan akun:** Admin dapat mengelola klasifikasi, data instansi, dan pengguna. Untuk membantu pengguna yang lupa kata sandi, buka **Data Pengguna** → **Atur Ulang Kata Sandi**. Kata sandi lama tidak bisa dilihat.

## Untuk Pengguna

**Masuk:** buka alamat aplikasi kantor, masukkan nama pengguna dan kata sandi, lalu pilih **Masuk**.

**Mencatat dan mencari surat:** pilih **Surat Masuk** atau **Surat Keluar** di menu kiri. Gunakan tombol **Catat** untuk menambah surat. Gunakan kotak **Cari** untuk mencari nomor, pengirim/tujuan, atau perihal. Anda dapat mengubah surat yang Anda catat sendiri.

**Membuat laporan:** buka **Laporan Surat Masuk** atau **Laporan Surat Keluar**, tentukan rentang tanggal, lalu pilih **Tampilkan laporan**. Untuk salinan kertas pilih **Cetak**; untuk berkas pilih **Unduh PDF** atau **Unduh Excel**.

**Profil dan bantuan:** buka menu nama pengguna untuk mengubah profil atau kata sandi. Pilih tombol **? Bantuan** pada halaman utama bila perlu petunjuk singkat. Jika tidak bisa masuk, hubungi Admin.
